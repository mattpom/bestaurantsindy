# BestaurantsIndy

An independent Indianapolis restaurant publication hosted by Sean Matthews.

**Editorial promise:** what to order, what it costs, and whether it is worth driving across town.

## Current status

This repository contains the active development source for BestaurantsIndy. The site is still in development. Provisional field notes intentionally omit restaurant names, prices, addresses, hours, and visit dates until those facts are verified.

## Website sections

- Home
- Reviews and searchable field notes
- Individual review pages
- Restaurant guides
- Neighborhood index
- About Sean Matthews
- Editorial policy

## Development

Requirements:

- Node.js 22.13 or newer
- npm

Install and run:

```bash
npm ci
npm run dev
```

Production build:

```bash
npm run build
```

## Content rules

- Never fabricate a restaurant visit, dish, price, quotation, address, hours, or opinion.
- Verify unstable restaurant information before publication.
- Label hosted meals, gifts, affiliate links, sponsored work, and paid placements plainly.
- Preserve the one-word brand name: **BestaurantsIndy**.
